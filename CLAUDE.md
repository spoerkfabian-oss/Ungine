## Architektur & Konventionen
- **Application:** Member-Reihenfolge `EventBus → Input → Window → VulkanContext → Renderer → ThreadPool → AssetManager` (Zerstörung umgekehrt). Loop: `Input::NewFrame → PollEvents → EventBus::Flush → (minimiert: WaitEvents) → FixedUpdate(1/60, Akkumulator) → AssetManager::Update → OnUpdate → BeginFrame/OnRender/EndFrame`. Frame-Time auf 0,25 s begrenzt.
- **Events:** typisiertes Pub/Sub, RAII-`Subscription`, `true` = konsumiert, re-entrancy-sicher, `Enqueue` threadsicher (Zustellung bei `Flush`).
- **ThreadPool:** feste Worker (hw−1), FIFO, `Submit → future` (Exceptions via future), `Enqueue` fire-and-forget (Exceptions geloggt); Dtor arbeitet Queue ab, dann Join.
- **Vulkan-Context:** 1.3 dynamicRendering + sync2; 1.2 BDA, Descriptor Indexing (UpdateAfterBind, UpdateUnusedWhilePending), Timeline-Semaphores, hostQueryReset; 1.0 Anisotropie, depthClamp, fillModeNonSolid, MDI. Dedizierte Transfer-Queue, sonst Fallback = Graphics-Queue. `ValidationErrorCount()` zählt Validation-Errors (Smoke-Tests).
- **Frames:** `kFramesInFlight = 2`; `FrameContext {cmd, image, view, format, extent, frameIndex, imageIndex}` (Swapchain-Image in COLOR_ATTACHMENT_OPTIMAL). Der Renderer besitzt **kein** Depth mehr (seit Phase 9 im SceneRenderer, pro Ausgabegröße); pro Frame Pool, Fence, Image-Acquired-Semaphore; Render-Finished-Semaphores pro Swapchain-Image. Fence-Reset erst nach erfolgreichem Acquire. Resize → `vkDeviceWaitIdle` + Recreate. Present-Barriere: dstStage = COLOR_ATTACHMENT_OUTPUT (muss im Signal-Stage-Mask liegen).
- **Koordinaten:** negativer Viewport-Y-Flip (+Y oben, glTF-CCW bleibt), Reverse-Z (Clear 0, `GREATER_OR_EQUAL`), `D32_SFLOAT`, Swapchain sRGB BGRA8.
- **Bindless:** Set 0: `0` texture2D[], `1` sampler[], `2` image2D[] (rgba16f), `3` textureCube[] (256), `4` image2DArray[] (rgba16f, 256; Cube-Faces für Compute). Eine Pipeline-Layout, 128 B Push-Constants (`STAGE_ALL`). Default-Sampler 0 LinearRepeat, 1 LinearClamp, 2 NearestClamp, 3 ShadowCompare (GREATER_OR_EQUAL, Border = Tiefe 0 = beleuchtet). In Compute nur `SampleTextureLod` (keine impliziten Ableitungen). **Add/Remove threadsicher (Mutex).**
- **Buffer-Zugriff:** Vertex Pulling per BDA, kein Vertex-Input-State.
- **Deferred Destruction:** `DeferRelease`/`DeferCall` (nur Main-Thread) → frei, wenn der Frame-Slot nach Fence-Wait wieder dran ist. UploadQueue-Ressourcen erst nach `IsReady(ticket)` freigeben.
- **Transient-Allocator:** 8 MB/Frame, host-visible + BDA (`PushTransient<T>`).
- **UploadQueue (Phase 5, Ring/Budget Phase 16):**
  - Beliebiger Thread: `CreateBuffer/CreateTexture2D/CreateTexture(format, w, h, data, mips)/WriteBuffer(…, UploadTicket&)` → **Staging-Ring** (`UploadQueueDesc::stagingRingSize` 64 MB, 16-B-Ausrichtung, Wrap; Upload > Ring/2 oder Ring voll → eigener Staging-Buffer, `Stats().dedicatedStaging`); memcpy + Copy-Recording unter Mutex in den offenen Batch. Batch über `frameBudget` (32 MB) → geschlossen. `CreateTexture` lädt alle Mips (BCn), keine Blits. Ticket = Timeline-Wert des Batches (max-akkumuliert). `Stats()`: Ring, wartende/laufende Batches, Bytes. `RendererDesc::upload`.
  - Main: `Renderer::BeginFrame` ruft `Submit()` (älteste Batches bis zum Budget, mind. einer → Transfer-Queue, signalisiert Timeline; Ring-Bereich frei, wenn der Batch fertig ist) und nach `vkBeginCommandBuffer` `RecordAcquires(cmd)`: fertige Batches → Acquire-Barrieren (QFOT) + Mip-Blits (Graphics) in den Frame-Cmd; Frame-Submit wartet auf den (bereits erreichten) Timeline-Wert (ALL_COMMANDS).
  - Transfer-Seite nur Mip 0; bei QFOT Release-Barrieren am Batch-Ende. Ohne QFOT (gleiche Queue) globale Memory-Barrier am Batch-Ende (sonst syncval-False-Positive über den Present→Acquire-Semaphore-Pfad).
  - `IsReady(t)` = Acquire in einem Frame aufgezeichnet. `Flush()` = blockierend (Startup/Shutdown). `ImmediateSubmit` = blockierend auf Graphics.
- **Assets (Phase 5; Ausbau Phase 16 siehe „Asset-Pipeline“):**
  - `AssetHandle<T>` (Index + Generation, 0 = null), `ModelHandle`. Handles halten Assets **nicht** am Leben.
  - `CreateModel(ModelData)` für generierte Geometrie (gleicher Lebenszyklus, nicht gecacht, Key leer).
  - `AssetManager` (Main-Thread): `LoadModel(path)` cached nach normalisiertem absolutem Pfad (Refcount+1), Job auf ThreadPool: `LoadGltf` + `BuildModel` (GPU-Ressourcen, Bindless-Slots, Upload). `Update()` pro Frame: Ergebnisse → Uploading → Ready (bei `IsReady`), Events `AssetLoadedEvent<Model>`/`AssetFailedEvent<Model>` (nach den Schleifen publiziert). `Release` bei 0: freigeben (Graveyard, falls Upload noch läuft; Orphan, falls Job noch läuft). Dtor: Jobs abwarten, `Flush()`, alles freigeben.
  - `MeshRenderer{ModelHandle, meshIndex}`; SpatialIndex/GpuScene lösen Handles per `ResolveMesh` auf (Ready → Modell, Failed → Platzhalter, sonst nichts).
  - `InstantiateModel(scene, handle, model)` – eine Entity pro Node (Eltern vor Kindern).
- **Datenlayouts (C++ ↔ GLSL):** `Vertex` 48 B (tangent.w = 0 → keine Tangente, Shader leitet Frame per Derivaten ab: (∇u, −∇v, N) = glTF-Konvention B = cross(N,T)·w), `GpuMaterial` 80 B (inkl. normalScale, occlusionStrength; Textur-Felder = **Texture-Table-Einträge**), `GpuSubmesh` 96 B (LOD 0 + lodCount + lodFirstIndex/lodIndexCount/lodError je 4), `GpuInstance` 128 B, `GpuDraw` 16 B, `GpuBatch` 32 B (scene_common.glsl), `FrameUniforms` (frame.glsl: viewProj/view/proj/invViewProj, Kamera, Sonne, sky.xy = Sky-/IBL-Intensität, ibl = Slots + Mip-Anzahl, Kaskaden, Cluster, lokale Schatten, hizInfo; BDA: lights, clusters, shadowViews, vertices/materials/submeshes (Pool), instances/draws (GPU-Szene), hiz, textureTable), `MeshPush` 24 B (frame, visible-Liste, cascade, flags). Visible-Eintrag = Draw-Record | LOD << 30. Vertex-Shader: `draw = frame.draws[pc.visible[gl_InstanceIndex] & 0x3FFFFFFF]` → Instanz (Matrix, Normalenmatrix, Entity-ID) + Submesh (Material) → flat an den Fragment-Shader.
- **SceneRenderer (Phase 6):** `Environment::Update` (Compute, nur bei geänderten SkySettings) → PBR-Forward in HDR-Target (RGBA16F, eigenes Image, Resize → DeferRelease) + Depth → Sky-Pass (Fullscreen-Dreieck bei Depth 0, analytischer Himmel + Sonnenscheibe) → Tonemap-Pass (texelFetch, PBR Neutral / ACES fitted / None, Exposure) in die Swapchain. Eine Mesh-Pipeline mit dynamischem Cull-Mode/Front-Face (Double-Sided, negative Determinante → CW). Frustum Culling pro Submesh (CPU, AABB-Weltbox nach Arvo). `lighting` (SkySettings + iblIntensity), `post` (exposure, tonemapper), `Stats()` (draws, culled, tris).
- **CSM (Phase 7):** `ShadowSettings` (Default 4 × 4096², maxDistance 60, λ 0,8, Bias konst./Slope, Normal-Offset in Texeln, PCF-Radius, Blend 10 %, Debug-Tint). `ComputeCascades`: Practical Split, Bounding-Sphere pro Slice (rotationsinvariant, Radius quantisiert), Texel-Snapping im Licht-Raum, Reverse-Z-Ortho (`OrthoReverseZ`). Shadow-Map = D32-Array (4 Layer), Layer-Views als Attachment + Bindless-Slot. Pass: kein Culling, Depth-Clamp (Pancaking), negativer Depth-Bias (Reverse-Z), Alpha-Mask-Pipeline, Culling pro Kaskade ohne Near-Plane (`Frustum::FromViewProjection(vp, false)`), nicht geflippter Viewport (UV = NDC·0,5+0,5). Sampling (`shadow.glsl`): Kaskade per View-Tiefe, 16 Poisson-Taps × 2×2 HW-PCF, IGN-Rotation, Cross-Fade zur nächsten Kaskade, geometrische Normale für den Offset.
- **Prepass + GTAO (Phase 8):** Depth-Normal-Prepass (mesh.vert mit `invariant gl_Position` + depth_normal.frag: Alpha-Test, Normal Mapping, View-Space-Normalen RGBA16F). Danach Depth → DEPTH_READ_ONLY; Hauptpass mit Depth-Test EQUAL, ohne Write, storeOp NONE; `DrawVisible()` gemeinsam für beide Pässe (gleiches Culling/Reihenfolge). GTAO (Compute, volle Auflösung, XeGTAO-Slice-Formel, 2 Slices × 4 Schritte/Seite, quadratische Schrittverteilung, Falloff, IGN-Rauschen) → 5×5-Bilateral-Denoise (relative Tiefendifferenz). AO-Targets RGBA16F in GENERAL. `AoSettings` (radius in Welt-Einheiten, falloff, power, slices, steps, sharpness). mesh.frag: `min(Material-AO, GTAO)` auf Diffuse-IBL, spekulare Okklusion nach Lagarde auf Specular-IBL; direktes Licht unberührt. Normal-Mapping-Code in `surface.glsl`.
- **Auto-Exposure (Phase 8):** Luminanz-Histogramm (256 Bins, log2-Bereich −10…+6, Shared-Memory-Atomics) → Average-Pass (geometrisches Mittel ohne Schwarz-Bin, exponentielle Adaption, Histogramm-Reset) → `ExposureState` (BDA) → Tonemap. Key 0,3 (0,18 = klassisches Mittelgrau, wirkt hier ~1 Blende zu dunkel), `post.exposure` = Kompensation. Readback pro Frame-Slot (nach Fence-Wait gelesen) → `Stats().exposure/averageLuminance`. Debug-Views im Tonemap (AO, Normalen).
- **Bloom (Phase 7):** halbe Auflösung, bis 6 Mips, RGBA16F in GENERAL (Sampled-Slots mit GENERAL registriert). 13-Tap-Downsample (erste Stufe Karis-Average), 3×3-Tent-Upsample additiv; Compute mit globalen Memory-Barrieren. Tonemap: `mix(hdr, bloom, strength)` vor Exposure. `PostSettings`: bloom, bloomStrength 0,04, bloomRadius 0,005.
- **PBR (mesh.frag):** glTF-Metallic-Roughness, GGX + höhenkorreliertes Smith + Schlick, Lambert, Roughness-Floor 0,045; IBL Split-Sum + Multiple-Scattering (Fdez-Agüera); AO nur auf indirektes Licht.
- **Environment (IBL):** Env-Cube 256² (9 Mips per Blit) → Irradiance 32² (512 Cos-Samples) + Prefiltered 128² (5 Mips = Roughness 0…1, 256 GGX-Samples, Filtered Importance Sampling) + BRDF-LUT 256² (einmalig). Sky-Funktion in `sky.glsl` für Skybox und IBL identisch (IBL ohne Sonnenscheibe). WAR-Barrieren gegen noch laufende Frames.
- **GPU-Profiler (Phase 9):** `Renderer::Profiler()`; Timestamp-Query-Pool pro Frame-Slot (max. 48 Scopes, Host-Reset), `GpuScope` (RAII, verschachtelt, Tiefe), Begin = TOP_OF_PIPE, End = ALL_COMMANDS. Ergebnisse beim Wiederbetreten des Slots (nach Fence-Wait) gelesen → `Results()` ist kFramesInFlight Frames alt, kein Stall. Scope "Frame" umfasst den ganzen Command-Buffer; SceneRenderer: Environment, Shadows, Depth + normals, GTAO, Forward, Sky, Bloom, Exposure, Tonemap; Editor: "Editor UI".
- **RenderOutput (Phase 9):** `SceneRenderer::Render(frame, scene, camera, RenderOutput{image, view, format, extent})` rendert in beliebiges Ziel (COLOR_ATTACHMENT_OPTIMAL rein/raus); alle Scene-Targets (Depth, HDR, AO, Bloom) auf `extent`; Tonemap-Pipeline pro Ausgabeformat (lazy). Ohne `RenderOutput` → Swapchain.
- **Editor (Phase 9, `editor/`):** Engine-Kern bleibt ImGui-frei. `ImGuiLayer` (privat): ImGui 1.92.9-docking, GLFW-Backend (verkettet die Engine-Callbacks), Vulkan-Backend mit Dynamic Rendering + eigenem Descriptor-Pool, Style auf sRGB-Swapchain linearisiert, keine Keyboard-Navigation (Tasten bleiben Engine-Hotkeys), `editor.ini` im Arbeitsverzeichnis (gitignored). Viewport-Texturen (RGBA8_SRGB) werden nach kFramesInFlight+1 **gerenderten** Frames freigegeben (eigene Liste, nicht Renderer-Deferred-Queue, weil sie das Backend nicht überleben darf). `Editor` (EditorContext = Window/Renderer/Scene/AssetManager/SceneRenderer/FlyCamera): Dockspace + Default-Layout (DockBuilder), Viewport (Szene → Textur, Größe = Panel, Toolbar), ImGuizmo (Translate/Rotate/Scale, Local/World; Reverse-Z + Infinite-Far werden von ImGuizmo unterstützt; Ergebnis → lokale TRS relativ zum Eltern-World), Hierarchy (Baum, Auswahl, Drag & Drop-Reparenting mit Erhalt der Weltposition, Kontextmenü Create child/Focus/Delete, Änderungen verzögert nach dem Zeichnen), Inspector (Name, TRS mit Euler-Cache gegen Flips, MeshRenderer-Info), Renderer (Licht/Sonne Az./Elev., Post, Schatten, AO, Kamera), Stats (CPU-Frame-Graph, GPU-Timings, Draw-/Cull-Stats, VMA-Heap-Budgets, Validation-Errors), Assets (`AssetManager::Models()` mit Status/Refcount/Fehler, Laden per Pfad, Instantiate, Release nur für im Editor geladene). Hotkeys nur bei gehovertem/fokussiertem Viewport: W/E/R, F Fokus, Entf. `FlyCamera::moveRequiresLook` (Editor: WASD nur mit RMB).

  - `Light`-Komponente (Components.h): Point/Spot, color, intensity in **Candela auf der Skala der Sonnen-Beleuchtungsstärke** (E = I/d²; Sonne 3,0), range (0 = aus Intensität, Cutoff `kLightCutoffIlluminance` 0,005 → `EffectiveRange`), inner/outer Kegel (Halbwinkel). Position/Richtung aus WorldTransform (lokal −Z, glTF). Skalierung beeinflusst die Reichweite nicht.

- **GPU-Driven Rendering (Phase 15):**
  - `GeometryPool` (Renderer::Geometry(), `RendererDesc::geometry`): 4 feste Buffer (Vertices 4 M, Indices 16 M, Materials 64 k, GpuSubmesh 256 k; `concurrent` Sharing → keine QFOT), `RangeAllocator` (First-Fit, Merge, Grow) pro Pool unter Mutex, `Upload` = Allokation + `UploadQueue::WriteBuffer` (Staging → Range, threadsicher, Worker). Pool voll → Ladefehler. `BuildModel` legt Vertices/Indices/Materials/Submesh-Records (absolute Offsets, Material-Flags, lokale Bounds) im Pool ab; `Model` hat `PoolRange vertices/indices/materials/submeshes` statt eigener Buffer, `Mesh::firstGpuSubmesh`; `ReleaseModel` gibt Ranges per `DeferCall` frei. Upload-Batches beginnen mit globaler Barriere (syncval-Fehlalarm bei Speicherwiederverwendung).
  - `GpuScene` (privat, pro SceneRenderer): persistente Instanzen (ein `GpuInstance` pro MeshRenderer), Draw-Records (Instanz × Submesh, `RangeAllocator`, freie Slots `instance = ~0`), Batches (Submesh + Spiegelung → Refcount, `instanceBase` = Präfixsumme; cameraBucket = double-sided | gespiegelt·2, shadowBucket = alpha-masked). Änderungen aus `SpatialIndex::MeshUpdates()` (bzw. `Meshes()` nach Rebuild); freigegebene Modelle (`m_ModelUse`) entfernen ihre Instanzen sofort (Pool-Freigabe erst Frames später). Upload pro Frame: nur geänderte Einträge per `scatter.comp` (Transient ≤ 2 MB, sonst eigener Staging-Buffer), Buffer wachsen (Neuanlage + Voll-Upload aus CPU-Spiegeln), Visibility-Buffer (1 uint pro Record).
  - `GpuCulling` (privat): Views pro Frame = Kamera early (0), Kamera late (1), Kaskaden, neu zu rendernde lokale Schattenkacheln (Frustum ohne Near für Kaskaden, + Reichweiten-Kugel lokal). `gpu_cull.comp`: Phase 0 (alle Views außer late: Welt-AABB nach Arvo vs. Ebenen; Kamera-early nur Records mit visibility = 1 bei Occlusion), Phase 1 (late: Frustum + Hi-Z-Test, zeichnet neu Sichtbare, schreibt visibility), Phase 2 (pro Batch × View: `VkDrawIndexedIndirectCommand` mit instanceCount = Anzahl, firstInstance = View-Listenbasis + instanceBase, per atomarem Zähler pro Bucket). Statistik-Zähler per Shared-Memory reduziert, Readback pro Frame-Slot (`GpuCullStats`, 2 Frames alt). Zeichnen: `vkCmdDrawIndexedIndirectCount` pro Bucket (Kamera 4: Cull-Mode/Front-Face dynamisch; Schatten 2: Pipeline mit/ohne Alpha-Test), ein Pool-Indexbuffer. Buffer (visible, counters, commands, drawCounts) von allen Frames geteilt, Barrieren gegen Vorframes.
  - Zwei-Phasen-Occlusion (Niagara-Stil): Prepass early → Depth READ_ONLY → Hi-Z (`hiz.comp`, Storage-Buffer, Level 0 = halbe Auflösung aufgerundet, Min-Reduktion 2×2 mit Clamping = konservativ, bis 1×1) → late Culling → Prepass late (LOAD) → Forward zeichnet early + late. Occlusion-Test: 8 Ecken der Submesh-Box projiziert (hinter der Kamera → sichtbar), Level mit ≤ 2×2 Texeln, verdeckt wenn nächste Tiefe < min Hi-Z. `CullingSettings` (`culling`): gpuDriven (Default an), occlusion, freeze (Kamera + Hi-Z des Einschaltmoments, Debug), hizDebugLevel; `gpuDriven`/`occlusion` in Szenendateien.
  - CPU-Pfad (Fallback/Vergleich): BVH-Query → Draw-Records der Instanzen (Submesh-Test bei Mehrteilern und Lichtreichweite) → Transient-Liste als `visible` → `vkCmdDrawIndexed(firstInstance = Listenposition)`. Gleiche Shader/Daten wie GPU-Pfad (Bildgleichheit im Test).
  - Debug-Views `HiZ` (Level hizDebugLevel), `Culling` (late gefundene Draws orange getönt). Stats: gpuDriven, instances/draws/batches, gpuTested/FrustumCulled/Occluded/Early/Late/Commands, drawCalls = Indirect-Aufrufe (GPU), cpuGpuSceneMs, Pool-Belegung. GPU-Scope "GPU culling". Editor: Renderer-Panel „Culling (GPU-driven)“, Stats-Panel-Abschnitt; Sandbox K (GPU/CPU), `--cpu-culling`, `--debug-view N`, Titel zeigt Instanzen/Batches/verdeckt.
- **Asset-Pipeline (Phase 16):**
  - **Texturen als Assets** (`TextureHandle`, `Texture.h`): `LoadTexture(path, TextureKind)` (Color = sRGB, Linear, Normal), gecacht nach Pfad + Kind; glTF-Bilder werden Quellen (`TextureData`: externe Datei → `LoadTexture`, eingebettet → per Inhalts-Hash FNV-1a geteilt, auch über Modelle/Reloads). Modelle halten Referenzen (`Model::textures`). Worker: `CookTexture` (TextureCooker: PNG/JPG/KTX2 → Mips auf der CPU (sRGB linear gefiltert, Normalen renormalisiert) → **BC7** (Color/Linear, bc7enc) / **BC5** (Normal, rgbcx; Shader rekonstruiert Z aus XY), ohne Kompression/BC-Support RGBA8; Cache `<cacheDirectory>/<hash>.ktx2`, Key = Quellbytes + Kind + Einstellungen + Cooker-Version, eigener KTX2-Reader/-Writer ohne Supercompression) → `UploadQueue::CreateTexture` + Bindless-Slot.
  - **Texture-Table** (Renderer): Materialien speichern Einträge, `FrameUniforms::textureTable` (uint[] pro Frame-Slot, host-sichtbar, bei Änderung in `BeginFrame` kopiert) bildet sie auf Bindless-Slots ab; `SampleMaterial()` (mesh_common.glsl). Einträge 0–3 = `DefaultTexture` White/Black/FlatNormal/**Error** (8×8 Magenta-Schachbrett). Ladend → neutraler Default, fehlgeschlagen → Color: Error, sonst neutral. Freigabe verzögert (`FreeTextureEntry`). `VulkanContext::SupportsBC()` (textureCompressionBC optional).
  - Modell-Job: `LoadGltf` → `OptimizeMeshes` (meshoptimizer: Vertex-Cache, Overdraw, Vertex-Fetch nur bei exklusiven Vertex-Bereichen; **LODs** bis 4 Stufen für Submeshes ≥ 256 Dreiecke, Ziel ×0,5 von LOD 0 aus, gesperrte Ränder, Fehler absolut im Objektraum, < 10 % Ersparnis → Stopp) → `BuildModelGeometry` (Worker) → Main: Texturen akquirieren → `BuildModelMaterials` (Materialien + GpuSubmesh-Records, CPU-Kopie `Model::gpuSubmeshes`). **Ready erst, wenn keine Textur mehr lädt.**
  - **Reload/Retry/Hot-Reload:** `Reload(handle)` (Modelle mit Datei/Rezept, Datei-Texturen): neuer Inhalt als `pending`, Tausch erst wenn hochgeladen (+ Texturen fertig); fehlgeschlagener Reload behält den alten Inhalt (Fehlertext + `AssetFailedEvent`); Failed → Retry; während eines Ladevorgangs vorgemerkt. `AssetManagerDesc` (über `ApplicationDesc::assets`): textures (compress, cacheDirectory `asset_cache/textures`, quality), meshes (`MeshOptimizeSettings`), hotReload, pollSeconds 0,5 → mtime-Polling von Quelle + Abhängigkeiten (externe .bin), entprellt (Änderung muss einen Poll stabil sein), fehlende Dateien laden beim Erscheinen. Events: `AssetLoadedEvent` (erstes Ready, auch nach Retry), `AssetReloadedEvent` (Inhalt getauscht), `AssetFailedEvent`. Textur-Reload tauscht nur den Tabellen-Eintrag.
  - **Revisionen:** `Revision(handle)` ändert sich mit der Antwort von `ResolveMesh` (Ready, Failed, Reload); `ContentVersion()` global (auch bei Release). SpatialIndex (Proxy-Revision, Rescan → ChangedRegions → Schatten-Cache), GpuScene (Instanz-Revision, Neuaufbau vor anderen Upserts), PhysicsWorld (Mesh-Shape-Key + Body mit Revision) folgen. **Platzhalter:** fehlgeschlagene Modelle rendern als 1-m-Box (Error-Textur, leicht emissiv), Physik nutzt ihn nicht.
  - **LOD-Auswahl:** jede (Submesh, Winding) belegt einen Block von lodCount Batches (`RangeAllocator`), jede Batch-Scheibe der Visible-Liste hat volle Kapazität (`GpuScene::VisibleCapacity`). `SelectLod` (GLSL + C++ identisch): gröbste Stufe mit `error · maxScale · pixelsPerUnit / lodPixelError ≤ Distanz(Kamera, Box-Mitte) − Box-Radius`; alle Views (auch Schatten) wählen nach der Kamera. CPU-Pfad gleiche Wahl (Bild-/Zählergleichheit getestet). `CullingSettings`: lod, lodPixelError (1 px, serialisiert), forceLod (Debug). DebugView::Lod (1 grün, 2 gelb, 3 rot). Stats: lodDraws.
  - **Shader-Hot-Reload** (`ShaderReload.h`): `ShaderHotReload` liest glslc-Depfiles (`*.spv.d`), pollt Quellen + Includes (entprellt), kompiliert mit Build-Flags (`ENGINE_GLSLC`, Debug `-g -O0`) nach `.tmp` → rename, Depfile-Ziel korrigiert (Ninja prüft es); Fehler → alte SPIR-V bleibt, `LastError()`. `Renderer::SetShaderHotReload/ShaderGeneration/NotifyShadersChanged`; SceneRenderer (`CreatePipelines`: erst alles bauen, dann tauschen, Tonemap-Cache leeren), Environment (+ IBL/LUT neu), GpuScene, GpuCulling bauen neu.
  - **Editor Assets-Panel:** Hot-Reload-Schalter (Assets + Shader), Shader-Status/Compile-Fehler, Staging-Ring/Queue/Jobs. Tab **Models**: Zustand („…“ = Reload läuft, „(!)“ = letzter Reload fehlgeschlagen, Tooltip), Refs, Dreiecke (+LODs), GPU/CPU-Speicher, Instantiate/Reload/Retry/Release. ## Offene Punkte / Einschränkungen
1. **Auf der GTX 1070 Ti mit Validation (+ Sync-Validation) laufen lassen** – prüft den QFOT-Pfad (höchste Priorität). MSVC `/W4` prüfen.
2. Resize nutzt `vkDeviceWaitIdle` (Stall); `VK_EXT_swapchain_maintenance1` wäre besser.
3. Minimiert gestartetes Fenster → 0×0-Swapchain nicht abgefangen. Uploads werden während Minimierung nicht submitted.
4. Event-Handler müssen kopierbar sein (`std::function`).
5. Upload: memcpy in den Ring unter dem Upload-Mutex (Worker serialisieren bei großen Texturen); voller Ring → eigener Staging-Buffer statt Warten; Budget in Bytes, nicht Transferzeit; Mip-Blits (nur `CreateTexture2D`) kosten Frame-Zeit auf der Graphics-Queue; laufendes Parsing/Kochen nicht abbrechbar (nur Skip beim Shutdown).
6. AssetManager: Hot-Reload per mtime-Polling (kein OS-Watcher); eingebettete Texturen nur mit ihrem Modell, `CreateModel`-Modelle gar nicht neu ladbar; ein Modell-Reload mit geänderter Knoten-Struktur passt bestehende Entities nicht an (meshIndex außerhalb → nichts gezeichnet); Textur-Cache wächst unbegrenzt; BC7 ohne RDO; Kochen im Debug-Build langsam (Cooker unoptimiert mit der Engine gebaut, Kaltstart WaterBottle ~5 s); gleiche Datei als Color und Linear = zwei Assets; Platzhalter nur als Box (keine Physik); Mesh-Collider eines neu geladenen Modells werden neu erzeugt (Kontakte brechen kurz ab).
7. Texturen: BC7/BC5/RGBA8 (+ BC1/3/4 aus KTX2), keine Basis-Supercompression/ASTC/BC6H/HDR, kein Mip-Streaming; Storage-Images im GLSL fest `rgba16f`. LODs: diskrete Stufen (Poppen, kein Dithering/Morphing), Auswahl nur nach Kamera-Distanz (Schatten ebenso), Visible-Liste × lodCount Speicher, LOD-Indizes bis ~+90 % Index-Speicher, keine Meshlets/Cluster-LOD. Shader-Hot-Reload kompiliert blockierend auf dem Main-Thread (`std::system`), nur mit glslc/Build-Verzeichnis; ImGui-Pipelines ausgenommen.
8. Kein `VkPipelineCache`; Shader über absoluten Build-Pfad (kein Asset-Packaging). Validation-Performance-Warnung „OutputNotConsumed“ (mesh.vert location 5/6 im Prepass) ist harmlos.
9. glTF: Blend unsortiert/opak; ignoriert COLOR_0, Sampler, UV-Sets > 0, Skins, Animationen, Morph-Targets, basisu/webp; externe `.bin` per `fopen` (Nicht-ASCII-Pfade unter Windows).
10. AO nur Screen-Space (keine Off-Screen-Occluder, kein Temporal-Filter → bei Bewegung leichtes Rauschen möglich); GTAO in voller Auflösung ohne Depth-MIP-Kette (große Radien = Cache-Misses); Auto-Exposure ohne Zentrumsgewichtung. Schatten nur für die Sonne (keine Punkt-/Spotlights); kein Contact-Hardening (PCSS), keine Schatten-Caches (alle Kaskaden jedes Frame); Kaskade 0 kann bei weiter Kamera sehr klein sein (λ-Tuning). Bloom ohne Lens-Dirt. Sonnenscheibe (40× Radiance) dominiert den Bloom.
11. CPU-Pfad-Culling per BVH (GPU-Pfad siehe 17); Raycast nur gegen AABBs (keine Dreiecke); SpatialIndex gehört dem SceneRenderer (ein Renderer pro Szene, einziger TakeChanges-Konsument), Queries nutzen den Stand des letzten Render; Transform-Schreibregel nicht erzwungen (nur Test-Check); MarkChanged für nachträgliche Light/MeshRenderer-Änderungen nötig; Welt-AABB der Meshes per Arvo (konservativ bei Rotation); kein Job-System-Paralleling von Transforms/Culling.
12. IBL-Regeneration bei jeder Sonnenänderung komplett (auf GPU ~ms; auf lavapipe langsam). Himmel ist ein einfaches analytisches Modell (kein Hosek/Bruneton).
13. Blend-Materialien weiterhin opak; Specular-/Clearcoat-/Transmission-Extensions nicht unterstützt.
14. Editor: Undo ohne Renderer-Settings (bewusst), Undo-Snapshots per JSON (bei sehr großen Teilbäumen spürbar), Modelle in Undo-Snapshots als rohe Handles (nach Release rendern wiederhergestellte Entities nichts), Picking ohne Box-/Lasso-Auswahl, Picking-Ergebnis 2 Frames verzögert, Outline nur für sichtbare Pixel (verdeckte Teile ohne Umriss), Inspector zeigt bei Mehrfachauswahl nur das primäre Objekt, Datei-Dialog ohne Überschreib-Rückfrage und ohne Laufwerksliste (Windows: Pfad eintippen), Szenen ohne Referenz-Prefabs/Sub-Szenen, generierte Modelle (`CreateModel`) nicht speicherbar, keine ImGui-Multi-Viewports (Fenster außerhalb des Hauptfensters). Viewport wird auch gerendert, wenn sein Tab verdeckt ist. Editor-Toggle (F1) wartet einmal auf GPU-Idle. Fokus (F) nutzt nur den Pivot, nicht die Bounds.
15. Lokale Schatten: Cache-Invalidierung pro Licht über die Reichweiten-Kugel (nicht pro Cube-Face/Frustum), bewegte Lichter rendern jedes Frame neu (keine Zeitscheiben), Lichter außerhalb von Sicht/Budget verlieren den Cache, einfache Verdrängung (Fragmentierung möglich), Materialänderungen (Alpha-Mask-Texturen) invalidieren nicht; CSM ohne Caching; Kachelgröße springt bei Wichtigkeitswechsel (sichtbares Poppen der Schärfe), Budget nur nach Bildschirmgröße (nicht nach Helligkeit/Sichtbarkeit von Empfängern), Spots > 85° nur teilweise beschattet, Caster näher als near (0,5 % Reichweite) werfen keinen Schatten, kein PCSS, Cube-Faces ohne Culling gegen das Kamera-Frustum (unsichtbare Faces werden trotzdem gerendert). Kein Area-/IES-Licht; keine Licht-Komponenten-Serialisierung. Cluster-Grid fest 16×9×24 (Kacheln bei extremen Seitenverhältnissen nicht quadratisch), Liste pro Cluster auf 256 begrenzt (Überlauf = fehlende Lichter, in der Heatmap weiß), Cluster-Buffer fix 3,5 MB. Kein Light-Culling gegen Tiefen-Min/Max (leere Froxel werden nicht übersprungen). Intensitäts-Einheiten nur relativ zur Sonne (kein physikalischer Sonnen-/Belichtungsmaßstab).
16. Physik: Jolt-Toleranzen absolut (Penetration-Slop 2 cm → Körper sinken sichtbar ~2 cm ein; Objekte < ~5 cm instabil), kein Continuous-Collision (MotionQuality Discrete; dicker Boden als Workaround), Mesh-Collider nur statisch/kinematisch (keine konvexe Hülle/Compound für dynamische Meshes), negative Skalierung ignoriert, Kapseln nur Y-Achse, dynamische Kinder bewegter Bodies folgen nicht korrekt (lokales Transform relativ zum alten Eltern-World), Character ohne Trigger-/Kontakt-Events (CharacterVirtual-Kontakte nicht im ContactListener), Character-Rotation nicht gesteuert, keine Joints/Constraints, keine Kollisions-Layer/Masken für Anwender, keine Physik-Materialien pro Dreieck, Collision-Events ohne Kontaktpunkt/Impuls, Kontaktpaar-Suche beim Entfernen O(Paare) pro Sync, Sync O(Bodies) pro Frame (auch im Edit-Modus), keine Interpolation zwischen Fixed-Steps (Ruckeln bei Framerate ≠ 60 Hz), Play-Snapshot mit rohen Modell-Handles (wie Undo), Inspector-Änderungen im Play gehen beim Stop verloren (gewollt), Physik-Einstellungen nicht serialisiert.
17. GPU-Driven: Geometrie-Pool fester Größe (kein Wachsen/Defragmentieren; Pool voll = Ladefehler; 256 MB Standard-Reservierung), Draw-Records/Visible-Listen pro View voll dimensioniert (Views × Records × 4 B), lokale Schattenkacheln und Kaskaden nur Frustum-Culling (kein Hi-Z pro Schatten-View), keine Meshlets/Cluster-Culling, keine Sortierung nach Material/Tiefe (Front-to-back) innerhalb der Buckets, Culling-Dispatch ≤ 4 M Records (65535 Gruppen), Statistik-Zähler 2 Frames alt, Zähler-Atomics pro Workgroup, Occlusion nur Kamera; bei schnellen Kamerabewegungen zeichnet der Late-Pass mehr (korrekt, aber teurer); Hi-Z-Debug-/Frame-Info aus dem Vorframe; transparente Objekte bleiben opak. `RenderOutput`-Viewport und Swapchain teilen sich Visibility (ein SceneRenderer pro Kamera empfohlen). Nicht auf echter GPU gemessen (lavapipe rastert auf der CPU).
