# Folder `assets/`

Sample content used by the developer sandbox, the tests and the installed engine.

| Folder | Contents | Used by |
|---|---|---|
| `models/` | Khronos glTF sample models: `WaterBottle.glb` (sandbox default), `BoxTextured.glb`, `MetalRoughSpheresNoTextures.glb`, `Fox.glb` (skinned, clips Survey/Walk/Run) | Sandbox, GPU tests, smoke tests, package smoke test |
| `scripts/` | Example Blueprints: `Rotator.ugraph` (spins its entity), `RainOnSpace.ugraph` (drops a batch of spheres each time Space is pressed) | Sandbox `--script`, script tests |
| `sounds/` | Synthesized sounds: `impact.wav`, `hum.wav`, `chime.wav`, `music_loop.wav` | Sandbox impact sounds, audio tests; copies live in `templates/*/Content/Sounds/` |

- Tests reach this folder through the compile definition `ENGINE_ASSET_DIR`; smoke tests run with
  the repository root as working directory.
- `models/`, `scripts/` and `sounds/` are installed to `bin/samples/` by `apps/CMakeLists.txt`.

## Adding content

- Only add content whose license allows redistribution and modification (CC0, CC-BY or own work);
  **no non-commercial (NC) licenses**. Add the credit to the matching `LICENSE.md`.
- Keep files small; they are part of every clone and every package.
- To regenerate the sounds: `cmake --build build --target MakeSounds`, then
  `build/tools/MakeSounds assets/sounds` (see [tools.md](tools.md)) and copy changed
  files into the templates that use them.
